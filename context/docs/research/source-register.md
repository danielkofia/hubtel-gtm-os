## Method note (important)

Hubtel's news pages (`news.hubtel.com`) render their article body with JavaScript, so a plain page fetch returned only headlines. This is why Pass 1 read S6 to S10, S14 and S15 as "headline only". In Pass 2 the same articles were retrieved through the site's public WordPress JSON feed (`news.hubtel.com/wp-json/wp/v2/posts?slug=...`), which returns the article text. Two limits remain:
1. The fetch tool passes content through a summarising model, so figures are **summaries of the page, not verbatim copies**. One extraction ambiguity was found (correction C2). Any figure that will be used in copy must be re-checked against the live page by a human.
2. All "Hubtel news" items are vendor-published. They show what Hubtel claims, not independent verification.
